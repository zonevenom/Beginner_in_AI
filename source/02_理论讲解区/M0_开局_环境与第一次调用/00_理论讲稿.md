## 一、大模型到底是个什么东西

### 先说结论

> **它是一个极其擅长"接话"的机器。**
> 你给它一段文字，它算出"下一个字最可能是什么"，然后把这个字接上去，再算下一个，一直接下去。

就这么简单。ChatGPT、DeepSeek、通义、文心，**本质上都在做同一件事：接话**。

### 一个你每天在做的事

你朋友说："今天下班路上堵得……"

你脑子里会自动蹦出："要死"、"不行"、"一塌糊涂"。

**你没有"思考"，你只是根据经验，觉得这几个词最可能接在后面。**

大模型干的是同一件事，只是它"读过"的书比你多几百万倍，所以它接得更准、更像个懂行的人。

### 那它为什么显得"懂很多"？

因为它读过的东西太多了。它把互联网上大量的文字"压缩"进了一堆数字里（这些数字叫**参数**）。

你可以把它想象成一个**看了几千万本书、但从不做笔记的人**：

- 他能跟你聊哲学、聊代码、聊菜谱——因为都看过
- 但他**记不清具体页码**——所以他会"编"，编得还挺像
- 他看完就忘，**不会记住你上次跟他说的话**（除非你把话再贴给他一遍）

这三条，解释了后面 90% 的"AI 怎么这么蠢"的现象。

### 由此推出三个必须记住的结论

| 现象 | 原因 | 对策（后面会学） |
|---|---|---|
| 它一本正经地胡说（幻觉） | 它在"接得像"而不是"查得准" | **RAG**：把真材料塞给它看（M4） |
| 它记不住上一轮对话 | 它天生没有记忆 | 把历史对话**每次重新发一遍**（M2） |
| 它算数经常错 | 它是"接话"不是"计算" | 让它**调工具**算（M6） |

> 把这张表记住。你后面 7 个模块，全是在解决这三行问题。

## 二、三个必须懂的词

### 1. Token（词元）—— 它按"块"收费

大模型不是按"字"处理文字的，它先把文字切成一块一块，每一块叫一个 **token**。

- 英文里，一个 token 大约 = 0.75 个单词
- 中文里，一个汉字**通常**是 1~2 个 token（常用字 1 个，生僻词可能 2 个）

**为什么要在意？** 因为：

1. **它按 token 收费**（输入多少 token、输出多少 token，分别计价）
2. **它一次只能看固定数量的 token**（见下一条）

> 比喻：坐出租车。不是你坐多远算多远，而是**按"跳表次数"算钱**。token 就是跳表次数。

### 2. 上下文窗口（Context Window）—— 它的"短期记忆"

模型一次能"看到"的 token 总量是有上限的，这个上限叫**上下文窗口**。

- 现在主流模型大概是 **几万到几十万 token**（各模型不同，以官网为准）
- 超过上限，最早的内容会被**挤出去**

> 比喻：一张书桌。桌上能摊开的纸就这么多，新纸放上来，旧纸就得掉下去。
> **它不是"忘了"，是"被挤下桌了"。**

这解释了：
- 为什么长对话聊到后面，它开始"忘记"你前面说的设定
- 为什么 RAG 不能把整本书塞进去，必须**先检索、再挑几段**
- 为什么"把 100 页 PDF 直接扔给模型"通常效果很差

### 3. Temperature（温度）—— 想象力的旋钮

一个 0 到 2 之间的数字（常用 0~1）：

| 值 | 效果 | 什么时候用 |
|---|---|---|
| 0 ~ 0.3 | 最稳、最一致，同样的问题基本同样答案 | 查资料、写代码、提取信息、输出 JSON |
| 0.7 左右 | 有点变化，但不离谱 | 日常聊天 |
| 1.0 以上 | 很飘，可能很有创意，也可能胡说 | 写文案、起名字、头脑风暴 |

> 比喻：**收音机的"清晰度"旋钮**。调低，信号干净但死板；调高，有杂音但偶尔能收到意外的台。

**这是你最早能"控制"模型的一个参数。** 记住：**要准确性就调低，要创意就调高。**

## 三、API 是什么：一次"点菜"的全过程

### 为什么不用网页版，要用 API？

网页版（chat.deepseek.com）是给人用的；**API 是给程序用的**。

你想让程序自动干活——批量处理 1000 条评论、接进你自己的网页、每天定时总结新闻——就必须走 API。

### 点菜比喻

| 点菜 | API |
|---|---|
| 你走进餐厅 | 你向 `https://api.deepseek.com` 发请求 |
| 你说"一份宫保鸡丁，不要辣" | 你发一段 JSON：`{"model":"deepseek-chat", "messages":[...]}` |
| 服务员记下菜单 | 服务器收到请求 |
| 厨房做菜 | 模型生成文字 |
| 端上来一盘菜 | 服务器返回 JSON，里面有文字 |
| 你付钱 | 按 token 计费 |

**整个过程是"一问一答"**：你发一个请求，它回一个结果，连接就断了。它**不会主动找你**。

### 请求长什么样（不用背，看懂结构就行）

```json
{
  "model": "deepseek-chat",
  "messages": [
    {"role": "system", "content": "你是一个小学老师，用最简单的词说话"},
    {"role": "user", "content": "什么是光合作用？"}
  ],
  "temperature": 0.3
}
```

三个 `role` 是核心：

| role | 谁说的 | 作用 |
|---|---|---|
| `system` | 你（在后台偷偷说） | 定人设、定规矩。**用户看不见** |
| `user` | 用户 | 提问 |
| `assistant` | 模型 | 回答（多轮对话时，历史回答也要放回去） |

> **`system` 是你最有力的武器。** 同一个问题，加一句 system，风格能完全变。M1 会专门练这个。

## 四、动手：把环境搭起来

> 🛑 **停一下**
> 下面这几步要往你电脑里装东西。**在动手之前，先告诉我"我要开始装环境了"，我确认后再往下。**
> 需要装的东西只有三样：**Python**、一个代码编辑器（VS Code）、**两个 Python 库**（`openai`、`python-dotenv`）。
> 全部免费，不改系统设置，不装驱动，不需要显卡。

### 第 1 步：装 Python

1. 去 https://www.python.org/downloads/ 下 **3.10 或更高版本**（3.10/3.11/3.12 都行）
2. 安装时**务必勾选** `Add Python to PATH`（这一步不勾，后面 90% 的报错都从这来）
3. 装完打开"命令提示符"（Win+R → 输入 `cmd` → 回车），敲：

```bash
python --version
```

看到 `Python 3.1x.x` 就成功了。如果提示"不是内部或外部命令"，说明 PATH 没配好，回去重装并勾选。

### 第 2 步：装一个编辑器

VS Code：https://code.visualstudio.com/ 。装完在扩展里搜 "Python"，装微软官方那个。

### 第 3 步：建项目文件夹 + 虚拟环境

**虚拟环境（venv）是什么？**
每个项目一个"独立工具箱"。A 项目要 1.0 版的库，B 项目要 2.0 版，放一起会打架。虚拟环境让它们各过各的。

```bash
# 1. 建文件夹（在你喜欢的位置，比如 D:\ai-study）
mkdir D:\ai-study\m0-hello
cd D:\ai-study\m0-hello

# 2. 建虚拟环境（这个文件夹叫 .venv，别动它）
python -m venv .venv

# 3. 激活（Windows）
.venv\Scripts\activate
```

激活成功的标志：命令行前面多了 `(.venv)`。

> ⚠️ 每次**新开一个命令行窗口**，都要重新激活一次。忘了激活 = 库装到"全局"去了，是新手第一大坑。

### 第 4 步：装两个库

```bash
pip install openai python-dotenv
```

- `openai`：官方 SDK。**注意：它能连 DeepSeek**，因为 DeepSeek 兼容 OpenAI 的接口格式。
- `python-dotenv`：从 `.env` 文件读配置，用来藏 API Key。

> 🛑 装之前问我一句。装的时候如果卡住/报错，把**完整报错**发我。

### 第 5 步：申请 API Key（要花钱，先问我）

1. 去 DeepSeek 开放平台注册，实名，创建一个 API Key
2. **复制下来，只显示一次**，丢了只能重建
3. 新用户一般有赠送额度，够你学完这个计划

> 💰 **我不会替你注册、不会替你付款。** 到这一步你告诉我，我给你讲清楚充多少、怎么最省。

### 第 6 步：把 Key 藏起来

在你项目文件夹里建两个文件：

**`.env`**（存钥匙，绝对不发给任何人）

```
DEEPSEEK_API_KEY=sk-你的key粘贴在这里
```

**`.gitignore`**（告诉 git "这个文件别上传"）

```
.env
.venv/
__pycache__/
```

> **为什么这么麻烦？** 因为 GitHub 上有成千上万个 Key 是被误传上去的，几分钟内就会被机器人扫走盗刷。
> **记住一句话：Key 写进代码 = 把银行卡密码写在卡背面。**

### 第 7 步：第一个程序

新建 `hello_llm.py`：

```python
import os
from openai import OpenAI
from dotenv import load_dotenv

# 1. 读 .env 里的钥匙
load_dotenv()

# 2. 建一个"客户端"，告诉它去哪家店、用哪把钥匙
client = OpenAI(
    api_key=os.getenv("DEEPSEEK_API_KEY"),
    base_url="https://api.deepseek.com",   # 换一家模型，只改这一行
)

# 3. 点菜
resp = client.chat.completions.create(
    model="deepseek-chat",
    messages=[
        {"role": "system", "content": "你是一个说话通俗易懂的老师，回答不超过三句话。"},
        {"role": "user", "content": "什么是大模型？"},
    ],
    temperature=0.3,
)

# 4. 上菜
print(resp.choices[0].message.content)

# 5. 看账单
print(resp.usage)
```

运行：

```bash
python hello_llm.py
```

> 如果它回你三句话，恭喜——**你已经跨过了 80% 的人卡住的第一道门。**

## 五、读懂返回结果

```python
resp.choices[0].message.content
```

拆开看：

| 部分 | 意思 |
|---|---|
| `resp` | 整个回执（像一个信封） |
| `.choices` | 候选答案的列表。**为什么是列表？** 因为可以一次要多个答案，但一般只用第 1 个 |
| `[0]` | 第 1 个候选 |
| `.message` | 这条消息 |
| `.content` | **真正的文字**（99% 的情况你只要这个） |

```python
resp.usage
```

会打印类似：

```
CompletionUsage(prompt_tokens=52, completion_tokens=87, total_tokens=139)
```

| 字段 | 意思 | 谁花钱 |
|---|---|---|
| `prompt_tokens` | 你发过去的（含 system） | 输入价 |
| `completion_tokens` | 它生成的 | 输出价（通常更贵） |
| `total_tokens` | 加起来 | 总账 |

> **养成习惯：每次跑完看一眼 usage。** 你会对"什么操作贵"建立直觉，这是 M2 成本控制的基础。

## 六、报错急救表

| 报错/现象 | 大概率原因 | 怎么办 |
|---|---|---|
| `401 Unauthorized` | Key 错了 / 没读到 `.env` | 检查 `.env` 文件名有没有多余后缀、有没有 `load_dotenv()` |
| `402 Insufficient Balance` | 余额不足 | 充值，或换成赠送额度内的模型 |
| `429 Too Many Requests` | 请求太快/太多 | 加 `time.sleep(1)`，或降低并发 |
| `Connection error` | 网络问题 | 检查网络；确认 `base_url` 没写错 |
| `ModuleNotFoundError: No module named 'openai'` | 没装 / 没激活 venv | 重新 `.venv\Scripts\activate` 再 `pip install` |
| `python 不是内部或外部命令` | PATH 没配 | 重装 Python，勾 "Add to PATH" |
| 返回内容是空的 | 被安全策略拦了 / 参数错 | 打印整个 `resp` 看 `finish_reason` |

> **排错三步法**：① 看报错**最后一行** ② 搜这一行的关键词 ③ 还不行，把"你想干什么 + 你敲了什么 + 完整报错"发我。

## 【常见误解】

**误解 1："它在思考。"**
不。它在算概率。它没有意图、没有情绪、不知道自己在说什么。"它理解我"是一种**错觉**，虽然这个错觉很有用。

**误解 2："我数学不好，学不了 AI。"**
做应用开发，你需要的是"知道 embedding 是什么感觉""知道温度调低会更稳"，**不需要会推导**。真正的数学在"训练模型"那一层，那不是你的方向。

**误解 3："模型越贵越好。"**
错。做 RAG 时，**检索质量比模型大小重要得多**。一个便宜的模型 + 好的检索，能打败贵模型 + 烂检索。这是 M4/M5 的核心思想。

**误解 4："我要先把 Python 学完再开始。"**
不要。"学完 Python"永远不存在。你现在的水平（变量、循环、函数）**足够开始**，缺什么补什么，缺的部分我会在项目里标注。
