## 🧠 第 1 题（概念）· 幻觉的根源

有人说："大模型像一个超级搜索引擎，能把答案从数据库里找出来。"

**这个说法错在哪？** 请用"接话"的原理，解释为什么大模型会在不知道答案时**一本正经地编造**，并说明这和搜索引擎的本质区别。

> 提示：想想"它是在'查'还是在'接'"。

## 🧠 第 2 题（概念）· 判断并改错

判断下面 5 句话对错，**错的请改正**：

1. 中文里一个汉字一定等于一个 token。
2. 上下文窗口满了以后，模型会自动把旧内容存到硬盘上，下次接着用。
3. temperature 设成 0，模型每次回答就完全一样了。
4. 在 `messages` 里，`system` 的内容用户是看不见的，但它对回答风格影响很大。
5. token 只在输出时计费，输入不计费。

## 💻 第 3 题（计算）· 算一笔账

假设某模型价格（**仅本题假设，真实价格以官网为准**）：

- 输入：2 元 / 百万 token
- 输出：8 元 / 百万 token

你的应用每天被调用 **5000 次**，每次请求：

- 输入 1200 token（其中 system 占 300 token）
- 输出 800 token

**问：**

1. 每天花多少钱？
2. 如果把 system 从 300 token 压到 100 token，每天能省多少钱？
3. 一个月（30 天）总共多少钱？

## 💻 第 4 题（代码）· 找出 4 个问题

client = OpenAI(api_key="sk-abc123def456")

resp = client.chat.completions.create(
    model="deepseek-chat",

    temperature=1.5,

print(resp.choices[0].text)
