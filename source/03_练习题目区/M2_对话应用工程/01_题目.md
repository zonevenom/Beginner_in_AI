## 🧠 第 1 题（概念）· 画出第 3 轮的消息数组

用户和你的助手这样对话：

- 第 1 轮：用户说"我叫张三"，助手说"你好张三"
- 第 2 轮：用户说"我在做电商"，助手说"好的，电商很有前景"
- 第 3 轮：用户说"我叫什么？"

**任务：**

1. 写出第 3 轮请求里 `messages` 数组的**完整内容**（按顺序，标出 role）。
2. 如果第 3 轮时**只发最后一句**会怎样？
3. 如果**漏存了**第 2 轮助手的回答，会怎样？

## 💻 第 3 题（计算）· 雪球有多大

前提：每轮对话（问 + 答）共 **300 token**，system 固定 50 token，价格按**输入 2 元 / 百万 token**算（仅本题假设）。

**任务：**

1. 不算 system，聊到第 20 轮时，**第 20 轮这一次**发过去多少 token？

## 💻 第 4 题（代码）· 写截断函数

写一个 `trim(messages, max_turns)` 函数：

- 永远保留第 0 条 `system`
- 只保留最近 `max_turns` 轮（1 轮 = 1 条 user + 1 条 assistant）
- 如果历史里的条目数不是偶数（比如最后一条 user 还没回答），**不能破坏配对**，要处理掉这种情况
- 返回新的列表，**不要修改原列表**

然后写出 3 个测试用例（含一个"奇数条"的边界情况）。

## 🔧 第 5 题（排错）· 流式的三个坑

你写了这段流式代码，出了三个问题：

```python
stream = client.chat.completions.create(
    model="deepseek-chat",
    messages=messages,
    stream=True,
)
full = ""
for chunk in stream:
    full += chunk.choices[0].delta.content
print(full)
```

**问题 A**：跑起来报 `TypeError: can only concatenate str (not "NoneType") to str`
**问题 B**：界面上一大坨文字是最后一次性出现的，没有打字机效果
**问题 C**：程序跑完想打印这次花了多少 token，但 `resp.usage` 是 `None`

**任务：**逐个说明原因，并给出修改后的完整代码。
