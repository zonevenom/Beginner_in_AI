## 一、这套材料怎么用（重要，先看这段）

1. **先看全貌**：双击 `00_知识图谱总览区/知识图谱.html`（星露谷风格农场地图，点建筑看详情），或打开 `00_知识图谱总览区/00_知识图谱.md`，5 分钟知道这 16 周要爬几座山。
2. **再看排期**：打开 `00_知识图谱总览区/01_学习计划总表.md`，找到你这周该学哪个模块。
3. **学理论**：读 `02_理论讲解区/Mx_.../00_理论讲稿.md`。这是我把多份资料嚼碎后用大白话重写的中文讲解，**不是复制粘贴**。
4. **做练习**：读 `03_练习题目区/Mx_.../01_题目.md`。**做完再翻** `02_答案与解析.md`，否则等于没做。
5. **做项目**：按 `04_实践项目区/Px_.../00_项目计划书.md` 一步步敲。
6. **想溯源**：每份讲稿开头都有【资料出处】，对应 `01_学习资料区/` 里的原始链接。

### 三条铁律

- **讲稿读不懂，再去翻原资料**。原资料是"出处"，不是"必读"，你不需要把 533 页的书啃完。
- **每个模块的顺序永远是：理论 → 练习 → 项目**。顺序反了，你会变成"只会复制代码的人"。
- **任何需要安装软件/申请账号的动作，我都不会擅自替你做，会先问你。**

## 三、16 周路线一句话版

| 阶段 | 模块 | 一句话 |
|---|---|---|
| 第 1–2 周 | **M0 开局** | 装好环境，写下人生第一行调用大模型的代码 |
| 第 3–4 周 | **M1 提示工程** | 学会"怎么说话"，让模型稳定输出你要的东西 |
| 第 5–6 周 | **M2 对话应用** | 做出会流式输出、记得上下文的聊天助手 |
| 第 7–8 周 | **M3 语义检索** | 让电脑"按意思"找东西，而不是按关键词 |
| 第 9–10 周 | **M4 RAG 核心** | 让你的文档变成可以提问的知识库 |
| 第 11–12 周 | **M5 RAG 进阶** | 检索变准、答案可评估、不再胡说 |
| 第 13–14 周 | **M6 Agent** | 让模型自己决定"该用哪个工具" |
| 第 15–16 周 | **M7 上线** | 部署、打包、写进简历 |

> 微调 / 本地模型（LoRA）作为**选修**放在 M7 之后的"进化方向"里，不占用主线。你的目标是应用开发，不是训模型。
