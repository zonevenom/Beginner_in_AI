# 网页05 · DeepSeek API 官方文档

- **链接**：https://api-docs.deepseek.com/zh-cn/
- **类型**：官方 API 文档
- **语言**：中文（官方原生）
- **对应模块**：M0、M1、M2（**必读**）
- **费用**：文档免费；调用按量付费，价格很低

---

## 为什么选它作为你的主力 API

| 对比项 | DeepSeek | OpenAI |
|---|---|---|
| 中文文档 | ✅ 官方中文 | 英文为主 |
| 支付方式 | 支付宝/微信 | 需要外币卡 |
| 网络 | 国内直连 | 需要额外手段 |
| 价格 | 极低 | 较高 |
| 接口格式 | **兼容 OpenAI 格式** | 原生 |

"兼容 OpenAI 格式"是关键：**你学的写法，换成任何一家国内模型都能用**，只改 `base_url` 和 `model` 两个参数。

---

## 文档里你需要看的四页

| 页面 | 内容 | 对应 |
|---|---|---|
| 快速开始 | 拿 API Key、第一个请求示例 | M0 |
| API 参考 → Chat Completions | 参数说明：model / messages / temperature / stream | M0、M2 |
| 模型与价格 | 有哪些模型、怎么计费 | M2（成本估算） |
| 错误码 | 401 / 402 / 429 / 500 分别什么意思 | 全程排错用 |

---

## 关键参数速记（背下来）

| 参数 | 作用 | 你常用值 |
|---|---|---|
| `model` | 用哪个模型 | `deepseek-chat` |
| `messages` | 对话历史，数组，每个元素有 `role` 和 `content` | 见 M2 |
| `role` | `system`（人设）/ `user`（你）/ `assistant`（模型） | 三种 |
| `temperature` | 随机性，0 最稳，1 最飘 | 事实类 0–0.3，创意类 0.7–1 |
| `stream` | 是否流式返回（打字机效果） | 界面用 `True` |

## 注意

- **API Key 等于你的钱包**。绝对不要写进代码、不要上传 GitHub、不要发给我。放在 `.env` 文件里，M0 会教你。
- 新注册通常有赠送额度，够你学完整个计划。**不要一上来充大钱。**
- 价格会变，**以官网为准**，我不在讲稿里写死数字。
