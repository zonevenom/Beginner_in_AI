# 网页06 · 工程文档合集（写代码时查）

> 这一个文件里放 4 个官方文档入口。它们不是"学"的，是"查"的。

---

## 1. FastAPI（中文文档）· M7

- **链接**：https://fastapi.tiangolo.com/zh/
- **用途**：把你的 Python 函数变成一个网址（别人能调用）
- **你只需看**：教程 → 第一步、路径参数、请求体、查询参数
- **跳过**：依赖注入高级用法、WebSocket、后台任务（用到再说）

---

## 2. Streamlit（英文，但代码即文档）· M2 / M7

- **链接**：https://docs.streamlit.io/
- **用途**：用纯 Python 三行代码做出网页界面，不用学 HTML/CSS
- **你只需看**：Get started → Basic concepts；API reference → `st.chat_input`、`st.chat_message`、`st.write_stream`、`st.file_uploader`
- **为什么英文也行**：这库的文档 90% 是代码块，看懂函数名就会用

---

## 3. Chroma（向量数据库）· M3 / M4

- **链接**：https://docs.trychroma.com/
- **用途**：把文本存成向量，按"意思"检索
- **你只需看**：Collections（增删改查）、Querying（查询）
- **关键概念**：collection ≈ 一张表；document ≈ 一条文本；embedding ≈ 它的向量

---

## 4. LangChain（英文）· M4 / M6

- **链接**：https://python.langchain.com/
- **用途**：把"模型 + 检索 + 工具"串成流水线
- **重要提醒**：这个库**版本变动极快**，2023 年的教程基本跑不通。看到 `ImportError` 先怀疑版本。
- **我的建议**：**M6 之前不要碰 LangChain**。先用原生代码把 RAG 和工具调用写一遍，理解原理，再用框架——否则你会变成"只会背 API 的人"。

---

## 一句话原则

> 官方文档 > 博客教程 > CSDN 转载。
> 报错时，先把报错的**最后一行**复制到搜索引擎，加个 `site:github.com` 或 `site:stackoverflow.com`。
