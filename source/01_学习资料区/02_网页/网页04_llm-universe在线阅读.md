## 这是什么

一本书教你"用 LLM API + LangChain 做一个应用"的教程，副标题大意是"基于 LLM API 与 LangChain 的大模型应用开发教程"。

它的结构非常贴合你的路线：

1. 大模型简介 → 对应你的 M0

**所以你其实是在"跟着这本书的骨架走"，只是我把每一步拆得更细、讲得更白。**
