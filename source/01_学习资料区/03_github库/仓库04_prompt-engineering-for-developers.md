## 它是什么

对吴恩达（Andrew Ng）与 OpenAI 合作的《ChatGPT Prompt Engineering for Developers》短课程的中文版整理，包含讲义、代码和课后练习。

原课程只有 1.5 小时，**极其适合你这种"周末只有两小时"的人**：一个周末就能看完，而且每个技巧都有可运行的例子。

---

## 能抄的三个具体东西

1. **"明确、具体、给例子"三原则**的具体写法。
2. **迭代改进的流程**：跑一次 → 看哪里不对 → 改一句 → 再跑。这是提示工程的真实工作方式。
3. **带分隔符的提示词模板**（用 `"""` 或 `###` 把用户输入和指令隔开）——这是防提示注入的第一道防线。
