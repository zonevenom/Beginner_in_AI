## 它是什么

一份面向"想从 API 走到本地大模型部署和微调"的中文逐步指南，代码提供 Kaggle / Colab 在线版本，**明确说明没有显卡也能学**。

这正好对上你的设备情况（笔记本无独显，可用免费云 GPU）。
