## 它是什么

"大模型应用开发实战一：RAG 技术全栈指南"。这是国内目前最系统的 RAG 中文实战项目，从"文档怎么读进来"一直讲到"怎么评估检索质量"。

对你最大的价值：**它把 RAG 拆成了可替换的零件**（解析器 / 切分器 / 嵌入模型 / 向量库 / 重排器 / 生成器），你能看到"换掉一个零件会发生什么"。

---

## 该看哪些

| 阶段 | 看什么 | 目的 |
|---|---|---|
| M4 开始前 | 整体流程图 | 知道有哪几个环节 |
| M4 做项目时 | 文档解析、切分、入库的代码 | 抄最小可用实现 |
| M5 优化时 | 不同切分/检索方式的对比 | 理解"为什么调这个参数" |
| M5 评估时 | 评估指标与脚本 | 做你的 20 条评测集 |

---

## 能抄的三个具体东西

1. **切分参数**：chunk_size / overlap 怎么定，别人踩过什么坑。
2. **提示词模板**：RAG 的"带上下文回答"提示词长什么样。
3. **评估表结构**：问题、标准答案、检索到的片段、是否命中——**这张表就是你 M5 的作业模板**。
