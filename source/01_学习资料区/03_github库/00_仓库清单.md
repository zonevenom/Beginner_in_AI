## 怎么用（重要，别搞反了）

| 阶段 | 能不能看代码 | 看什么 |
|---|---|---|
| 学理论时 | ❌ 别看 | 看代码会让你跳过理解 |
| 做练习时 | ⚠️ 卡 20 分钟以上再看 | 只看"思路"，别抄 |
| 做项目时 | ✅ 可以看 | 看**文件怎么分、函数怎么命名、异常怎么处理** |

**抄结构，不抄实现。** 别人用 LangChain，你用原生 requests，都能做出同样的东西——后者更锻炼你。

## 访问提醒

国内直连 GitHub 有时很慢或打不开。可用的办法（按推荐顺序）：

1. 等一会儿重试（多数是临时抽风）
2. 用 Gitee 上别人同步的镜像（搜仓库名 + Gitee）
3. 用 `https://ghproxy` 类加速前缀（自己搜当前可用的，**不要用来源不明的加速站，有盗号风险**）

> 需要具体操作时问我，我不会让你随便装来路不明的工具。
