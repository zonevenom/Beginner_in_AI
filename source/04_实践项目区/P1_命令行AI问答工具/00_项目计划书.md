## 1. 项目要做什么

### 一句话

做一个能在命令行里跟你连续对话的小工具：输入问题，它回答；输入 `exit` 退出；退出时告诉你这次花了多少 token。

### 验收标准（做到这 6 条才算完成）

- [ ] 双击运行（或命令行 `python main.py`）能启动
- [ ] 启动后先显示一句欢迎语，提示可以输入 `exit` 退出
- [ ] 能连续问 3 个以上问题，不会崩
- [ ] 每个回答前面有 `你：` 和 `AI：`，能分清谁在说话
- [ ] 输入 `exit`（大小写都行）能正常退出
- [ ] 退出时打印本次对话的总 token 数

### 明确**不做**什么（防止跑偏）

- ❌ 不做记忆（M2 才做）
- ❌ 不做界面（M2 才做）
- ❌ 不接数据库
- ❌ 不调用第三方库（除了 `openai` 和 `dotenv`）

> 这一版丑、笨、没记忆，**但它跑得起来**。跑得起来比什么都重要。

## 3. 项目文件结构

```
m0-hello/
├── .env                  ← 存 API Key（绝不外传，不进 git）
├── .gitignore            ← 告诉 git 忽略 .env 和 .venv
├── .venv/                ← 虚拟环境（自动生成，别手动改）
├── main.py               ← 主程序（你写的所有代码都在这）
└── chat_log.txt          ← 对话记录（程序自动生成，可选）
```

### 每个文件干什么

| 文件 | 谁创建 | 作用 | 能不能删 |
|---|---|---|---|
| `.env` | 你 | 存 `DEEPSEEK_API_KEY=sk-xxx` | 删了程序连不上模型 |
| `.gitignore` | 你 | 防止 Key 被上传 GitHub | 删了有泄露风险 |
| `.venv/` | 命令自动 | 隔离的库环境 | 删了要重装库 |
| `main.py` | 你 | 全部逻辑 | 核心 |
| `chat_log.txt` | 程序 | 记录历史对话，方便复盘 | 随便删 |

> **为什么第一版就只有一个 `main.py`？**
> 因为现在拆文件只会让你多写 `import`。**等到文件超过 300 行再拆**（M3 会拆）。过早设计架构是新手最大的时间黑洞。

## 4. 项目流程图

```mermaid
flowchart TD
    A([开始]) --> B[打印欢迎语<br/>读取 .env 里的 Key]
    B --> C{Key 存在吗}
    C -- 否 --> C1[提示"没找到 Key"<br/>并退出]
    C -- 是 --> D[初始化 client<br/>指向 DeepSeek]
    D --> E[/等待用户输入<br/>input/]
    E --> F{输入是 exit?}
    F -- 是 --> Z[打印总 token 数<br/>结束]
    F -- 否 --> G[组装 messages<br/>system + 本轮 user]
    G --> H[调用 API<br/>chat.completions.create]
    H --> I{调用成功?}
    I -- 否 --> I1[打印报错摘要<br/>继续下一轮]
    I1 --> E
    I -- 是 --> J[取出 content 打印]
    J --> K[累加 prompt/completion token]
    K --> L[追加写入 chat_log.txt]
    L --> E
```

### 看懂这张图的三个要点

1. **循环体是"等待输入 → 调用 → 打印 → 回去等"**，`exit` 是唯一的出口。
2. **报错不能让程序崩**，要能回到等待输入（这叫"容错"）。
3. **token 累加在循环里**，不在循环外。

## 5. 分步实现（一步一停，每步都能跑）

### Step 0 · 建项目（10 分钟）

**目标**：文件夹建好，虚拟环境激活。

```bash
mkdir D:\ai-study\m0-hello
cd D:\ai-study\m0-hello
python -m venv .venv
.venv\Scripts\activate
```

**怎么验证**：命令行前面出现 `(.venv)`。

**可能踩的坑**：
- PowerShell 报"无法加载文件，因为在此系统上禁止运行脚本" → 用 `cmd` 而不是 PowerShell，或先执行 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`

---

### Step 1 · 装库、放 Key（10 分钟）

```bash
pip install openai python-dotenv
```

建 `.env`：

```
DEEPSEEK_API_KEY=sk-你复制的key
```

建 `.gitignore`：

```
.env
.venv/
__pycache__/
chat_log.txt
```

**怎么验证**：

```bash
python -c "import os; from dotenv import load_dotenv; load_dotenv(); print('Key 长度:', len(os.getenv('DEEPSEEK_API_KEY','')))"
```

输出 `Key 长度: 51`（或类似正数）= 成功。输出 `0` = `.env` 没被读到。

**为什么先做这一步**：Key 读不到，后面所有代码都是白写。**先把最容易出错的地方验证掉。**

---

### Step 2 · 最小可运行：问一句、答一句（20 分钟）

**目标**：先不管循环、不管美化，只要能答一次。

新建 `main.py`：

```python
import os
from openai import OpenAI
from dotenv import load_dotenv

load_dotenv()

client = OpenAI(
    api_key=os.getenv("DEEPSEEK_API_KEY"),
    base_url="https://api.deepseek.com",
)

resp = client.chat.completions.create(
    model="deepseek-chat",
    messages=[{"role": "user", "content": "你好，请用一句话介绍你自己"}],
)
print(resp.choices[0].message.content)
```

**运行**：`python main.py`
**验证**：看到模型回话。

**为什么先写这个**：这是整个项目的"心脏"。心脏不跳，别急着搭骨架。

---

### Step 3 · 加人设（10 分钟）

**目标**：让它变成"小助"，说话简短、友好。

在 `messages` 前面加一条 `system`：

```python
messages=[
    {"role": "system", "content": "你叫小助，是一个说话简短友好的助手。每次回答不超过 3 句话，不说客套话。"},
    {"role": "user", "content": "你好，请用一句话介绍你自己"},
]
```

**验证**：回答明显变短、变随意，且会说"我是小助"。

**为什么**：`system` 是控制风格最有效的手段（M1 的核心）。这里先体验一次，M1 会系统讲。

---

### Step 4 · 加循环（20 分钟）

**目标**：能连续问，`exit` 退出。

```python
print("小助已上线。输入 exit 退出。\n")

while True:
    q = input("你：")
    if q.strip().lower() == "exit":
        print("小助：再见！")
        break

    messages = [
        {"role": "system", "content": "你叫小助，是一个说话简短友好的助手。每次回答不超过 3 句话。"},
        {"role": "user", "content": q},
    ]

    resp = client.chat.completions.create(
        model="deepseek-chat",
        messages=messages,
        temperature=0.7,
    )
    print("小助：", resp.choices[0].message.content, "\n")
```

**验证**：连续问 3 个问题，都能答；输入 `exit` 能退出。

**踩坑预警**：
- 在 VS Code 的"输出"面板里可能无法输入 → **改用终端（Terminal）运行**，或直接在 cmd 里跑。
- 中文乱码 → 在文件第一行加 `# -*- coding: utf-8 -*-`，或确认文件保存为 UTF-8。

---

### Step 5 · 加 token 统计（15 分钟）

**目标**：每次回答后显示用量，退出时显示总计。

```python
total_prompt = 0
total_completion = 0

# ……在 while 循环里，拿到 resp 之后：
    usage = resp.usage
    total_prompt += usage.prompt_tokens
    total_completion += usage.completion_tokens
    print(f"   [本次 {usage.prompt_tokens}+{usage.completion_tokens} token]")

# ……在 break 之后（循环外）：
print(f"本次会话共消耗：输入 {total_prompt}，输出 {total_completion}，合计 {total_prompt + total_completion} token")
```

**验证**：问 3 次后退出，合计 ≈ 三次之和。

**踩坑预警**：`break` 之后、循环外的 print 缩进**必须顶格**，否则会被当成循环体，永远不执行（或者语法错误）。

---

### Step 6 · 加容错（20 分钟，**这一步最值钱**）

**目标**：网络断了、Key 错了、余额没了，程序都不能崩。

```python
from openai import APIError, APIConnectionError, RateLimitError, AuthenticationError

    try:
        resp = client.chat.completions.create(...)
    except AuthenticationError:
        print("❌ Key 无效，请检查 .env 文件。")
        break
    except RateLimitError:
        print("⏳ 请求太频繁，等 2 秒再试。")
        time.sleep(2)
        continue
    except APIConnectionError:
        print("🌐 网络连接失败，检查网络后重试。")
        continue
    except APIError as e:
        print(f"⚠️ 接口出错：{e}")
        continue
```

**别忘了** `import time`。

**怎么验证（必须做）**：
1. 把 `.env` 里的 Key 改错一个字母 → 应该看到"Key 无效"，而不是一大坨红色报错。
2. 断网 → 应该看到"网络连接失败"。
3. 改回来 → 一切正常。

> **这一步为什么值钱**：面试官问"你的程序健壮吗"，你能说出"我处理了 401/429/断网三类异常"——这比"我调通了 API"高一个档次。

---

### Step 7 · 记录日志（15 分钟，可选但推荐）

**目标**：每次对话存到 `chat_log.txt`，方便复盘。

```python
from datetime import datetime

def log(role: str, text: str):
    with open("chat_log.txt", "a", encoding="utf-8") as f:
        f.write(f"[{datetime.now():%Y-%m-%d %H:%M:%S}] {role}: {text}\n")
```

在打印前后各调一次：`log("你", q)` / `log("小助", answer)`。

**注意 `encoding="utf-8"`**。Windows 默认编码不是 UTF-8，不写这一句，中文会变成乱码或直接报错。**这是 Windows 上最常见的坑之一。**

## 6. 项目进化方向（从"能跑"到"能打"）

你做完 P1 会很想继续加功能。**按这个顺序加，别乱跳**：

| 等级 | 加什么 | 需要先学 | 对应项目 |
|---|---|---|---|
| Lv.1 | 加 `--temperature` 命令行参数 | `sys.argv` | 自己练 |
| Lv.2 | 加多轮记忆（记住上文） | messages 追加历史 | **P3** |
| Lv.3 | 加流式输出（打字机效果） | `stream=True` | **P3** |
| Lv.4 | 换成 Web 界面 | Streamlit | **P3** |
| Lv.5 | 让它能查你的文档 | RAG | **P5** |
| Lv.6 | 让它能调工具（查天气、算数） | Function Calling | **P7** |

### 三个"看起来很酷但先别做"的功能

| 功能 | 为什么先别做 |
|---|---|
| 语音输入输出 | 要装音频库，环境问题会吃掉你两个周末 |
| 接入微信/QQ | 要处理登录、风控、封号，和 AI 无关 |
| 自己训练一个模型 | 你有 16 周，训练模型 16 个月起步 |
